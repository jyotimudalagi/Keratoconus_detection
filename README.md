# Keratoconus_detection
4 Keratoconus classification notebooks comparing backbones for 3-class (Keratoconus/Normal/Suspect) eye-image classification: VGG16 &amp; VGG19 (frozen-feature transfer learning), ConvNeXtV2-tiny (timm, weighted sampling + dropout), and Swin-B Transformer (timm, focal loss, heavy augmentation). All use PyTorch, torchvision, sklearn metrics.
